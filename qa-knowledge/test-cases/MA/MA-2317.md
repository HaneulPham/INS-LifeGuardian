## Duplicate Review

- Existing related test cases checked: Yes — the supplied Confluence mirror page 2521038850 v1 and current MA-2317 page 2599747585 v218.
- Duplicate coverage found: Yes — the mirror's 27 executable cases overlap the current routing, login, registration, recovery, plan, and persistence suite.
- Overlapping test cases: Mirror TC#1–TC#27 are represented by one or more current v218 cases.
- Decision: Store 153 unique current cases; merge one exact current duplicate and the overlapping mirror cases.
- Merged test cases: 27 mirror cases.
- Removed test cases: Source MA-2317-G5.1-10 is merged into stored MA-2317-G19-05 because both verify the same callback request, Home route, toast, no-plan state, billing non-trigger, and evidence.
- Unique verification retained: iOS/Android routing, Connect handoff, OTP recovery, account resolution, multiple devices, billing/promo/referral, offline/reactivation, new registration, subscription/callback, resume, persistence, privacy isolation, and simulated-alarm non-trigger behavior.
- Conflict retained: mirror TC#28 process-death waiver and TC#30 billing-purchase exclusion conflict with current resume/subscription coverage; mirror TC#29 wearable exclusion remains Out of Scope.
- Notes: Source execution-result columns were not copied because observations require separate defect/acceptance evidence and contain environment-specific test data.
