# Raw Evidence Notes

Use this folder to reference original source evidence such as ticket text, screenshots, PDFs, Confluence exports, Jira exports, API notes, and historical test evidence.

Do not store sensitive client data, credentials, tokens, production identifiers, or temporary rendered evidence here unless the user explicitly approves it.

Recommended note content:

- Source name
- Date received
- Ticket ID, if known
- Evidence type
- Short summary
- Sensitive data warning, if applicable
- Related ticket/feature note
