# SMAR-2537 - Group 4: Permissions / Security / Access Control

This note captures permission, security, and access-control coverage for SMAR-2537. Restricted-account cases are intentionally included even though normal CP Desktop testing may use a full-permission account.

This group verifies that only authorised users can configure, create, edit, delete, and listen for generated medi-alarms.
