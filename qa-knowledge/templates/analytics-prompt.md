# Analytics Command

```text
analytics

Use the active INS LifeGuardian ticket and all evidence already available.
Perform any material QA analysis needed for the ticket, including requirements, gaps, conflicts, questions, decisions, risks, test groups, API/backend, permissions/privacy, integrations, jobs/queues, notifications, audit/history, reports, historical data, recovery, regression, feedback, and automation suitability.

Do not write detailed test cases, update the QA Second Brain, modify automation code, invent expected behaviour, or claim unsupported root cause.
Show only material findings and preserve traceability.
```
