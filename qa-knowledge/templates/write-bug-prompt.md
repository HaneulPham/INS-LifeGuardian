# Write a Bug Command

```text
write a bug

Use the active INS LifeGuardian defect evidence to create one Jira-ready bug report.
Separate observed Actual Result from evidence-backed Expected Result, and Severity from Priority.
Include reproducible steps, environment/build/platform, frequency, business/safety/privacy/integration impact, evidence, regression risk, and workaround when supported.
Do not write test cases, invent expected behaviour, expose sensitive data, or claim root cause without evidence.
```
