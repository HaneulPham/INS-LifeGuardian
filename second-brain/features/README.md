# Feature Knowledge

Use this folder for durable feature memory by INS LifeGuardian module.

Feature notes should separate:

- Confirmed requirements
- Observed behavior
- API/backend knowledge
- Permissions
- Notifications/jobs/queues
- Audit/history/logs
- Reports/exports
- Cross-platform sync
- Known risks
- Regression impact
- Open questions

Do not replace current Jira requirements or verified API contracts with feature memory. Mark uncertain details as `Needs confirmation`.
