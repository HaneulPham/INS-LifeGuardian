## Requirement Summary

SMAR-2303 standardizes State formatting across the CP Desktop, CP Web, and Portal Web shared address controls. Australian addresses use one of eight abbreviated State or Territory values, while non-Australian State remains free text. Auto-search, manual entry, the individual State field, and Formatted Address must remain consistent. Existing address data requires a controlled Raven-to-AWS correction and synchronization process.

## Confirmed Scope

- CP Desktop: Service Request Create/Edit, Provider Create/Edit, Village Create/Edit, Client File Property, Client Doctor/Pharmacy/OT, and Emergency Contacts.
- CP Web: Work Order Details and Invoice Details.
- Portal Web: Address Change Request, GP & Pharmacy, and Emergency Contacts.
- Australian dropdown values, invalid-value restriction, auto-search/manual formatting, immediate display, persistence, and non-Australian free text.
- Backend enforcement of the Australian State rule; exact contracts remain open.
- Historical correction in Raven, Client File synchronization through ReSyncFiles, AWS reconciliation, exception reporting, and retry behavior.

## Out of Scope

- Address Change Request approval or downstream Client File lifecycle beyond the existing Portal workflow; SMAR-2303 changes address formatting, not approval behavior.
- Unnamed reports and exports until the outputs required by R14 are supplied.
- Mobile SOS and Mobile Carer; neither is listed by SMAR-2303.

## Business Rules

1. Australian State values use only NSW, QLD, VIC, WA, SA, TAS, NT, and ACT.
2. Non-Australian State values remain free text and are not converted to Australian abbreviations.
3. State and Formatted Address must not show mixed full-name and abbreviated Australian State values.
4. Country changes preserve State only when the value remains valid for the new Country.
5. Historical correction preserves unrecognized values and identifies them for review rather than silently clearing them.

## UI/UX Rules

- Country Australia displays a dropdown/combo box rather than unrestricted free text.
- Auto-search and manual entry display the same abbreviated State representation.
- Formatted Address updates immediately after address or State selection.
- Saved values remain consistent after refresh or reopen.

## Validation Rules

- Valid Australian values: NSW, QLD, VIC, WA, SA, TAS, NT, and ACT.
- Full State names and arbitrary values cannot be persisted as the Australian State through the shared controls or Backend APIs.
- Non-Australian State remains free text.
- Invalid Australian State input causes no accepted partial address update.

## API / Backend Impact

A partial platform deployment or incomplete migration can preserve mixed formatting, allow backend bypass, alter non-Australian regions, desynchronize Raven and AWS, or change report grouping and filtering.
