## Duplicate Review

- Existing related cases checked: SMAR-2638 and SMAR-2658.
- Partial overlap exists in shared-HMAC rejection patterns.
- Decision: Retain all 12 approved SMAR-2650 IDs because they uniquely cover these four API Gateway routes, additive API-key protection, deployment bypass risk, and CRUD persistence.
- No duplicate titles or IDs are introduced.

## Shared Execution Controls

- Use synthetic non-production Client File and criteria data, isolated credentials, and sanitized evidence.
- Never store authentication material, real client information, internal hosts, or tenant identifiers.
- Establish exact signing and rejection contracts from approved documentation or a protected control.
- Group 1 is developer-only.
- Capture before/after state and remove only disposable records.
