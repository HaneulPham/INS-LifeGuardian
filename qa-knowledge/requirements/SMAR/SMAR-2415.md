## Requirement Summary

SMAR-2415 modifies the CP Web **Services Installed Summary** report for DVA monthly reporting. The generated report adds **Price** and **Purchase Type**, separates the same product when Work Order item prices differ, and displays quantity-weighted average prices for Purchase and Rental items at the bottom. The report period must include only services installed in the selected period, including Rentals installed in that period rather than all current Rentals.

## Confirmed Scope

- CP Web **Reports → Work Orders Reports → Services Installed Summary**.
- Generated report columns, row values, grouping, footer averages, and Installed Date filtering.
- Purchase and Rental Work Order item data, including edited item prices.
- Targeted regression for the existing **Services Installed** report.

## Out of Scope

- QuickBooks invoice/export mappings; SMAR-2415 changes the Services Installed Summary report only.
- Work Order item-price editing rules themselves; the ticket consumes the persisted item price.
- Production DVA report execution with real client or service data.

## Business Rules

- Price comes from the applicable Work Order item, not only the product default.
- Purchase and Rental use separate weighted-average populations.
- Quantity contributes to the weighted numerator and denominator.
- Different prices are separate grouping keys even when Product Code is the same.
- Installed Date limits the report population; current Rentals outside the selected period are excluded.

## UI/UX Rules

- The generated Services Installed Summary output includes Price and Purchase Type after the existing columns.
- Average Purchase Price and Average Rental Price appear in the report footer when the selected dataset supports those figures.
- Exact dollar-symbol presentation is unresolved under GAP-01.
