## Group 3 — HSTS Header on 5xx Response

### Deferred Source Case

- `SMAR-2538-G3-01` — Verify a 5xx API response includes the Strict-Transport-Security header.
- Preserve this source ID for future completion.
- Do not execute by breaking, disabling, or degrading shared infrastructure.
- The case becomes executable only after the approved target endpoint, HTTP method, controlled failure trigger, expected 5xx status, recovery path, and evidence source are supplied.
- Required outcome: the genuine 5xx response contains `Strict-Transport-Security: max-age=31536000; includeSubdomains`, omits no required existing error content, is not converted to another status class, and exposes no unexpected sensitive/internal detail because of the header change.

### Requires Test Instrumentation

- Development or Operations must provide an isolated and reversible failure mechanism, complete response-header capture, the expected genuine 5xx status/body, and evidence that shared users and services are unaffected.

### Test Data and Cleanup

- Use only an approved non-production fixture. Record the restoration or reset result after the controlled failure. Preserve privacy-safe evidence and remove temporary failure configuration through the approved recovery path.
