# Review Playwright API Automation Command

```text
review API automation for <case IDs, ticket ID, files, or current changes>

Review contract accuracy, traceability, API-only boundaries, authentication/authorization, tenant isolation, exact response assertions, negative behavior, test independence, safe data, cleanup, secrets, polling, duplication, mapping, and execution evidence.
Return Pass, Pass with Changes, or Blocked. Do not change approved product behavior merely to make code pass.
```
