# INS LifeGuardian QA Second Brain

This folder stores durable QA memory for INS LifeGuardian.

It is designed for:

- Ticket analysis
- Requirement gap review
- Screenshot/document evidence handling
- Feature knowledge preservation
- Risk and defect prediction
- Regression planning
- QA handover consistency

## Source priority

Use this order when evidence conflicts:

1. Current Jira requirement or confirmed BA/product decision
2. Verified API contract or current product behavior
3. Feature context files in the repository
4. Second-brain notes
5. Historical screenshots, documents, or old test evidence

When unsure, mark the item as `Needs confirmation`.
