# Debug Playwright API Automation Failure Command

```text
debug API automation failure for <case ID or result/report path>

Use the approved case, contract, Playwright report/JSON result, redacted request/response, correlation IDs, and available logs. Classify Product Defect, Automation Defect, Test Data, Authentication, Authorization, Environment, Dependency, Requirement Conflict, Could Not Verify, Requires Test Instrumentation, or Flaky Under Investigation before proposing a fix.
```
