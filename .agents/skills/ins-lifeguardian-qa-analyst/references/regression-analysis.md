# Regression analysis

Trace direct and indirect impact across the changed feature, shared APIs/data, other clients, integrations, jobs, notifications, reports, and audit/history.

For each meaningful relationship, state:

- Changed area and dependent flow
- Affected platforms or consumers
- Failure consequence and priority when useful
- Observable regression validation
- Whether existing behaviour must remain unchanged
- Evidence or Source Status supporting the relationship

Check `qa-knowledge/regression/regression-map.md` and related approved cases first. Reuse Confirmed relationships, label assumptions, and report conflicts. Avoid generic “test regression” statements and avoid expanding scope without an evidence-backed dependency.
