## Requirement Summary

SMAR-2633 corrects DVA rental invoice dates when the Work Order Install Date and Prior Approval date (`Presc On`) differ. At invoice generation, CP Web calculates and persists the invoice Rental Start Date. Validation and DVA XML export then use the persisted invoice values rather than recalculating from current Work Order data.

The canonical Rental Start Date calculation is:

`Rental Start Date = StartOfMonth(Max(Install Date, Presc On))`

Rental Start Period Date also depends on invoice lifecycle. For a Work Order that has never been invoiced, the first invoice uses the calculated Rental Start Date as its Rental Start Period Date. For a later invoice, the period date follows the applicable invoice cycle; the reviewed recurring scenario derives it from the pre-generation Next Inv Due relationship. This distinction supersedes the earlier G1-03 expectation that a never-invoiced Work Order could immediately produce an earlier period date and fail IVL027.

## Business and Lifecycle Rules

1. Select the later of Work Order Install Date and Presc On and normalize it to the first calendar day of that month.
2. Persist the result as Rental Start Date at invoice generation.
3. Generate Rental End Date as the last calendar day of the Rental Start Date month.
4. If the Work Order has never been invoiced, set Rental Start Period Date equal to Rental Start Date.
5. If the invoice is later in the lifecycle, derive Rental Start Period Date from the applicable invoice cycle; use the correct pre-generation Next Inv Due context when preparing test data.
6. Do not retroactively recalculate an existing invoice when Work Order dates change.
7. Use persisted invoice dates for validation and XML export.
8. Keep Work Order source dates, unrelated invoices, and historical exports unchanged.
9. Keep Buy and Recycle on their existing non-rental workflow.

## UI, Validation, and Export Rules

- Rental Start Date and Rental End Date are editable only for Pending or Rejected invoices.
- Rental Start Period Date and Rental End Period Date are read-only in all statuses.
- Rental Start Date must be the first day of its month.
- Rental End Date must be the last day of its month, including leap-year February and 30/31-day months.
- Failed edit validation persists neither the invalid value nor a partial update.
- IVL027 fails only when Rental Start Period Date is earlier than Rental Start Date.
- The exact message is `Rental Period Start date is before the Rental Start date.`
- IVL027 equality and later-period cases pass.
- An IVL027 failure blocks the affected invoice from export and creates no new XML or successful submission record.
- Persisted Rental Start Date maps to XML `HireStartDate`; persisted Rental Start Period Date maps to `HirePrdStartDate`.
- A repeated export action must not create a duplicate successful DVA submission.
