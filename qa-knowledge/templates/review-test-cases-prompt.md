# Review Test Cases Command

```text
review test cases

Review the active or supplied INS LifeGuardian test cases against the latest ticket evidence, confirmed decisions, approved groups, case style, and full quality gate.

Classify findings as Add, Update, Merge, Remove, Defer, Reject, or Retain.
Check IDs, priorities, traceability, duplicates, executable setup and steps, exact expected outcomes, integration evidence, privacy, cleanup, and unresolved behaviour.

Return only:
1. Review Result — Pass / Pass with Changes / Blocked
2. Required Changes
3. Deferred or Could Not Verify
4. Readiness — approved group, more groups remain, or suite ready for storage

Do not rewrite unrelated cases.
```
