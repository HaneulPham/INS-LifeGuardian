# SMAR-2537 - Group 3 Listen for Alarm Runtime Matching

This note captures **Group 3: Listen for Alarm** runtime coverage for SMAR-2537. Groups 1 and 2 are saved in `SMAR-2537-new-service-request-steps-for-peripherals.md`.

Group 3 validates that **Listen for Alarm** only completes when the received alarm matches the generated medi-alarm, Client File, parent/main device, eligible peripheral, Service Request context, and active listener session.
