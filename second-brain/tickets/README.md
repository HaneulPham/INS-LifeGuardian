# Ticket Notes

Use one file per Jira ticket, requirement, or change request.

Recommended filename:

```text
SMAR-xxxx-short-feature-name.md
```

Each ticket note should preserve:

- Requirement summary
- Business intent
- Source evidence
- Confirmed behavior
- Observed screenshot/document behavior
- Assumptions
- Conflicts
- Open questions
- Impact analysis
- Risk level
- Likely defects
- Test focus areas
- Related feature, decision, risk, bug, and regression notes
