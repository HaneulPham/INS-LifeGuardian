# SMAR-2503 - CP Web Auto Expand General Comments Field

## Ticket Summary

Auto-expand the **General Comments** field so long comments are fully visible instead of being clipped by a fixed-height field.

## Confirmed Scope

- Platform: **CP Web**.
- Applies to all Work Order types, not only **DVA**.
- Applies wherever the same **General Comments** field is visible on:
  - **Work Orders**
  - **Invoice Details**
- Field keeps the current/default minimum height of about 3 lines.
- When text exceeds 3 lines, the field expands vertically.
- The field should shrink back to the minimum height when content is removed or reduced.
- Fields/sections below **General Comments** move down or back up with the resized field.
- Page-level vertical scrolling should appear when expanded content exceeds the visible screen.
- Internal field scrollbar is not expected for this ticket; page scroll is expected.
