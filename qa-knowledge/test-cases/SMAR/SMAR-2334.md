## Duplicate Review

- Existing related stored cases checked: SMAR-2325 Document Field History; related Jira tickets SMAR-1046, MA-2064, MA-2105, and MA-2106.
- Duplicate coverage found: repeated source rows differed only by explicit `EditedBy` enum value and expected display label.
- Decision: Merge the five Create variants into G1-03 and the five Update variants into G2-03 as explicit data matrices.
- File-field and Medication checks were removed from unrelated platform cases and retained as dedicated G1-05/G1-06 outcomes.
- All supported values, labels, defaulting variants, invalid outcomes, history formats, and no-partial-data checks remain covered.

## Shared Execution Controls

- Use synthetic non-production Client Files, File/Client values, and medication names/dosages.
- Keep SHM authentication material in protected test configuration; do not store it in requests, screenshots, logs, or this knowledge base.
- Correlate API responses and Document Field History using synthetic identifiers, then redact them from shared evidence.
- Record baseline values/history counts before updates and rejected requests.
- Remove only disposable Client Files through supported actions while preserving required audit evidence.
