# Bug report style

Use this order:

- Title
- Summary
- Environment
- Path
- Preconditions
- Steps to Reproduce
- Actual Result
- Expected Result
- Frequency
- Severity/Priority
- Impact/Notes

Use a searchable title and reproducible steps. Actual Result is observed behaviour; Expected Result comes from a requirement or confirmed business rule. Label inferred expectations as QA assumptions. Do not claim root cause without code, API/database, log, or developer evidence. Record build, environment, role, attachments, safety/operational impact, notifications, integrations, data integrity, and regression risk when supported.
