# Direct Second Brain Update Command

```text
Update test cases to Second Brain
```

Provide or link the approved Confluence test cases in the same conversation. This command directly authorizes Codex to retrieve the source, apply the full quality review, make safe non-behavioural corrections, reconcile IDs/counts/traceability, update all relevant QA Second Brain files and indexes, preserve history, run backups and strict validation, and report every change.

No second approval phrase is required. Do not invent product behaviour. Preserve unsupported or conflicting items as Could Not Verify, Open Question, Conflict, or GAP while updating unaffected valid content.
